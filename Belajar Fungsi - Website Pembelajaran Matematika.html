# 1. Pengertian

Fungsi linier adalah fungsi yang grafiknya berupa garis lurus.

f(x) = ax + b

a = gradien (kemiringan), b = titik potong sumbu y. Jika a > 0 garis naik, jika a < 0 garis turun.

# 2. Cara menggambar grafik

1) Titik potong sumbu y: x = 0, hasilnya (0, b).
2) Titik potong sumbu x: f(x) = 0, hasilnya x = −b/a.
3) Hubungkan kedua titik dengan garis lurus.

# 3. Contoh: f(x) = 2x − 4

x = 0 → f(0) = −4 → titik (0, −4)
2x − 4 = 0 → x = 2 → titik (2, 0)
gradien = 2 (garis naik)

# 4. Fungsi dari dua titik

Garis melalui (1, 3) dan (3, 7).

m = (7 − 3) / (3 − 1) = 2
y − 3 = 2(x − 1)
y = 2x + 1

# 1. Pengertian

Fungsi kuadrat grafiknya berupa parabola.

f(x) = ax² + bx + c , a ≠ 0

Jika a > 0 parabola terbuka ke atas (punya titik minimum). Jika a < 0 terbuka ke bawah (titik maksimum).

# 2. Unsur-unsur grafik

titik potong sumbu y : (0, c)
titik potong sumbu x : ax² + bx + c = 0
diskriminan : D = b² − 4ac
sumbu simetri : x = −b / 2a
titik puncak : (−b/2a , −D/4a)

D > 0: memotong sumbu x di dua titik. D = 0: menyinggung sumbu x. D < 0: tidak memotong sumbu x.

# 3. Contoh: f(x) = x² − 4x + 3

a = 1, b = −4, c = 3
D = (−4)² − 4(1)(3) = 4 (dua akar)
(x − 1)(x − 3) = 0 → x = 1 atau x = 3
sumbu simetri x = 4/2 = 2
f(2) = 4 − 8 + 3 = −1 → puncak (2, −1)
titik potong y = (0, 3)
